# پرواز شاهد — Shahed Flight

بازی تحت‌وب الهام‌گرفته از بازی موبایلی «پرواز شاهد»: شبیه‌ساز عملیات پهپاد رزمی.
تمام بازی با HTML، CSS و JavaScript خالص (Canvas 2D) نوشته شده است — بدون هیچ کتابخانه، فونت محلی یا فایل صوتی؛ صداها با WebAudio ساخته می‌شوند.

## اجرا

فایل `index.html` را مستقیم باز کنید، یا یک سرور ساده بالا بیاورید:

```bash
python3 -m http.server 4173
# سپس http://localhost:4173
```

## کنترل‌ها

| عمل | ماوس | لمس | کیبورد |
| --- | --- | --- | --- |
| هدایت پهپاد | حرکت ماوس | کشیدن انگشت | جهت‌ها یا WASD |
| شلیک | نگه‌داشتن کلیک | نگه‌داشتن انگشت | Space |
| موشک نقطه‌زن | دکمهٔ وسط صفحه | دکمهٔ وسط صفحه | F |
| توقف | دکمهٔ ⏸ | دکمهٔ ⏸ | P یا Esc |
| صدا | دکمهٔ 🔊 | دکمهٔ 🔊 | M |

## مکانیک‌ها

- **عملیات‌های پشت‌سرهم:** هر عملیات سهمیهٔ مشخصی هدف دارد؛ عبور اهداف از منطقه به پایگاه آسیب می‌زند و در صورت صفر شدن جان پایگاه، مأموریت شکست می‌خورد.
- **ناوچهٔ مادر:** هر چهار عملیات یک‌بار ظاهر می‌شود؛ تا انهدام آن، امواج بالگرد و آتش سنگین ادامه دارد.
- **دشمنان:** بالگرد، جت، گالکسی سنگین و پهپاد انتحاری (که به سمت شما کشیده می‌شود).
- **حرارت اسلحه:** شلیک ممتد توپ را داغ و قفل می‌کند؛ رها کنید تا خنک شود.
- **جعبه‌های تجهیزات:** مهمات، تعمیر، سپر و خنک‌کننده روی میدان ظاهر می‌شوند.
- **موشک نقطه‌زن:** با هر انهدام شارژ می‌شود و آسیب منطقه‌ای می‌زند.
- **امتیاز:** زنجیرهٔ انهدام ضریب تا ×۶ می‌دهد؛ بهترین امتیاز در `localStorage` ذخیره می‌شود.

## ساختار

```
index.html        رابط بازی، HUD و صفحه‌های منو/راهنما/پایان
css/style.css     طراحی شیشه‌ای و ریسپانسیو، پشتیبانی از RTL و موبایل
js/game.js        موتور بازی: حلقه، برخورد، ذخیره‌سازی، رسم، جریان مأموریت
js/sfx.js         موتور صدا با WebAudio (موتور پهپاد، شلیک، انفجار، هشدار)
```

## نکات فنی

- مختصات جهانی با ارتفاع ثابت و مقیاس‌پذیر: یک صحنه برای دسکتاپ و موبایل.
- ذرات با سقف مشخص برای حفظ فریم‌ریت؛ رندر لایه‌ای با مرتب‌سازی عمق دشمنان.
- پشتیبانی از `prefers-reduced-motion`، توقف خودکار هنگام مخفی‌شدن تب، ذخیرهٔ بهترین امتیاز به‌صورت محلی.
